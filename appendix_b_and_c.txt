APPENDIX B: DATA DICTIONARY
================================================================================

B.1 WATER QUALITY DATASET (2_Water_Quality_Data_NE_India.csv)
--------------------------------------------------------------------------------
Field Name                Data Type   Description
--------------------------------------------------------------------------------
village                   String      Name of the village
state                     String      State in Northeast India
date                      Date        Date of water quality test
water_source_id           String      Unique ID for water source
water_source_type         String      Type (Tube Well, Pond, Piped Supply, Well)
latitude                  Float       GPS latitude of water source
longitude                 Float       GPS longitude of water source
pH                        Float       pH level (6.5-8.5 = safe)
turbidity_ntu             Float       Turbidity in Nephelometric Turbidity Units
bacteria_ecoli_cfu_100ml Float       E. coli count per 100ml (0 = safe)
bacteria_coliform_cfu_100ml Float   Total coliform count per 100ml
dissolved_oxygen_mg_l     Float       Dissolved Oxygen (DO) in mg/L
nitrates_mg_l             Float       Nitrate concentration in mg/L
phosphates_mg_l           Float       Phosphate concentration in mg/L
heavy_metals_mg_l         Float       Heavy metals concentration
chlorine_residual_mg_l    Float       Chlorine residual in mg/L
fluoride_mg_l             Float       Fluoride concentration in mg/L
arsenic_mg_l              Float       Arsenic concentration in mg/L
test_method               String      Test method (IoT Sensor, Lab Analysis)
testing_agency            String      Agency responsible for testing
is_potable                Integer     1 = Potable (Safe), 0 = Non-potable
contamination_level       String      Level (Safe, Low, Moderate, High, Severe)
depth_meters              Float       Depth of water source in meters

--------------------------------------------------------------------------------
Field Name                Data Type   Description

date                      Date        Date of report
report_time               DateTime    Exact time of report submission
patient_age_group         String      Age group (0-5, 6-18, 19-45, 46-60, 60+)

diarrhea_cases            Integer     Number of diarrhea cases reported
fever_cases               Integer     Number of fever cases reported
vomiting_cases            Integer     Number of vomiting cases reported
stomach_pain_cases        Integer     Number of stomach pain cases reported
dehydration_cases         Integer     Number of dehydration cases reported
nausea_cases              Integer     Number of nausea cases reported
headache_cases            Integer     Number of headache cases reported
weakness_cases            Integer     Number of weakness cases reported
asha_worker_id            String      Unique ID of ASHA worker
clinic_reports            Integer     Number of reports from clinics
villager_self_reports     Integer     Number of self-reported cases
total_population          Integer     Total population of the village
households_affected       Integer     Number of households affected
severity_level            String      Severity (Mild, Moderate, High, Severe)

APPENDIX C: USER MANUAL &amp; DEPLOYMENT GUIDE
================================================================================

C.1 USER MANUAL

C.1.1 VILLAGER (COMMUNITY MEMBER)
--------------------------------------------------------------------------------
1. Open Neersetu Mobile App / Community Web Portal
2. Select your preferred language (Assamese, Bengali, English, Hindi, Manipuri)
3. View real-time water quality status of nearby sources
4. Check health alerts and advisories
5. Submit simple health reports (optional)
6. Access health awareness content

C.1.2 ASHA WORKER
--------------------------------------------------------------------------------
1. Login with ASHA credentials
2. Collect &amp; submit detailed health reports
3. View comprehensive water quality data
4. Receive priority alerts for high-risk areas
5. View community health trends and analytics
6. Coordinate with health officials

C.1.3 GOVERNMENT OFFICIAL
--------------------------------------------------------------------------------
1. Login with official credentials
2. Access real-time dashboard with village-wise data
3. View ML-based outbreak predictions
4. Monitor water quality across multiple villages
5. Generate and download reports
6. Manage alerts and notifications
7. View analytics and trend analysis

C.1.4 ADMINISTRATOR
--------------------------------------------------------------------------------
1. Login with super admin credentials
2. Manage all user accounts and roles
3. Configure system settings and parameters
4. View system logs and audit trails
5. Manage IoT sensors and data sources
6. Train and update ML prediction models
7. Perform backup and restore operations

C.2 DEPLOYMENT GUIDE

C.2.1 PREREQUISITES
--------------------------------------------------------------------------------
- Node.js v16+
- Python 3.8+
- MongoDB 5.0+
- Docker &amp; Docker Compose (optional, for containerized deployment)

C.2.2 BACKEND DEPLOYMENT
--------------------------------------------------------------------------------
1. Navigate to backend directory:
   cd backend

2. Install dependencies:
   npm install

3. Configure environment variables in .env file:
   - MONGO_URI: MongoDB connection string
   - JWT_SECRET: Secret key for JWT tokens
   - PORT: Server port (default: 5000)

4. Start the backend server:
   npm start
   (For development: npm run dev)

C.2.3 ML SERVICE DEPLOYMENT
--------------------------------------------------------------------------------
1. Navigate to ML service directory:
   cd ml-service

2. Create virtual environment:
   python -m venv venv
   source venv/bin/activate  (Windows: venv\Scripts\activate)

3. Install dependencies:
   pip install -r requirements.txt

4. Train ML models (first-time setup):
   python src/train_models.py

5. Start ML service:
   python src/enhanced_api.py
   (API runs on http://localhost:8000)

C.2.4 DASHBOARD DEPLOYMENT
--------------------------------------------------------------------------------
1. Navigate to dashboard directory:
   cd dashboard

2. Install dependencies:
   npm install

3. Configure API endpoint in src/config.js

4. Start dashboard:
   npm start
   (Runs on http://localhost:3000)

C.2.5 MOBILE APP DEPLOYMENT (OPTIONAL)
--------------------------------------------------------------------------------
1. Navigate to mobile app directory:
   cd mobile-app

2. Install dependencies:
   npm install

3. Configure API endpoints in app/config.js

4. Run on Android/iOS:
   npx expo start
   (Scan QR code with Expo Go app)

C.2.6 DOCKER DEPLOYMENT (RECOMMENDED)
--------------------------------------------------------------------------------
1. From project root directory:
   docker-compose up -d

2. Services will be available at:
   - Backend: http://localhost:5000
   - ML Service: http://localhost:8000
   - Dashboard: http://localhost:3000
   - MongoDB: mongodb://localhost:27017

C.2.7 VERIFICATION
--------------------------------------------------------------------------------
1. Check all services are running
2. Access dashboard at http://localhost:3000
3. Test API endpoints using tools like Postman
4. Verify ML predictions by submitting test data
